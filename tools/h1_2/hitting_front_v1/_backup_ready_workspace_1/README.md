## 本次落实的改动

1. **物理碰撞**：在新场景生成、物理初始化之前开启 articulation self collision。
   在USD session layer配置碰撞过滤：双侧上臂yaw子link、肘、腕与球拍，对躯干和
   骨盆的22对碰撞开启；其他机器人内部碰撞对维持旧配置禁用行为，保留外部过滤。
   肩部pitch/roll关节安装壳体不在这次非相邻碰撞对中；没有放开所有相邻关节碰撞。
   不保存或重写任何原始USD，不关闭球拍—球、脚—地面接触。
   接口依据 [IsaacLab2.1 articulation配置](https://github.com/isaac-sim/IsaacLab/blob/v2.1.0/source/isaaclab/isaaclab/sim/schemas/schemas_cfg.py)
   及 [OpenUSD FilteredPairsAPI](https://openusd.org/release/api/class_usd_physics_filtered_pairs_a_p_i.html)。

2. **几何与坐标校验**：读取原 handless URDF，不重建资产。按PhysX实际关节顺序做FK，
   对照当前USD的全部受保护link位置/朝向，位置误差<2mm、旋转矩阵元素误差<.005
   才允许继续。球拍固定安装变换取自当前USD。碰撞盒由当前启用的collision几何读取，
   不是把视觉网格中心或关节原点当作碰撞几何。没有collider/映射不一致时明确停止。

3. **胸前准备与击球空间**：先以IK找右臂准备目标，拍心在躯干局部+X方向，拍面法向
   先朝前。准备位必须通过所有受保护碰撞盒及起始姿态到准备位的采样路径检查。
   前5秒逐步移向准备目标，不写关节/根节点状态。5秒后要求**整个球拍碰撞盒**
   在躯干前表面至少3cm之外，持拍腕原点在前表面至少2cm之外。以当前躯干坐标
   定义“前”，跟随转身，不是固定世界X阈值。上臂可在体侧，但不能侵入受保护躯干几何。

4. **下发目标过滤**：保留两模型分别的观测。双腿/躯干13个动作通道不变；双臂14个
   目标在原关节硬限位内，肩/肘目标速度≤.6rad/s、腕≤.9rad/s；从当前实际关节角到
   候选目标按最大关节步距.025rad采样，检查受保护碰撞盒至少1cm分离余量及前方约束。
   候选不合格则回退步长，仍无合格路径就停止，不把关节瞬移到准备位。
   这些速度/余量是本轮保守工程参数，未经实机或完整技能验收。

5. **实际状态监测**：每个物理子步读取手臂/球拍→躯干/骨盆过滤法向接触力；>0.1N
   视为违例。每控制步检查实际关节姿态下的几何与前方约束。任何违例终止首次回合，
   保存原始状态，不能记为通过；与20秒超时同时发生也不能被当作成功。
   原球拍—球物理接触记录保留，不拿距离奖励充当真实碰撞证据。

注意：碰撞盒是保守包围体，可能拒绝原本能通过的贴身动作。采样路径过滤不是
连续时间数学保证，PhysX也有有限步长/求解误差；必须结合实际接触/姿态监测和GUI
判断。该脚本是防穿身控制候选的局部验证，不能在容器执行前声称已彻底解决穿模。
当前范围不覆盖手臂互撞、手臂对腿、球桌等所有障碍的完整避碰规划。

奖励真实有效击球、拍心/拍面/时机，惩罚身体接触、低余量和目标变化。随后再扩大发球、
恢复身体追球及整机微调。不能放宽碰撞保护换取旧策略分数，也不能把有穿身轨迹的旧模型
直接称作完整技能。本包不自动开始训练，既有模型/任务/保护清单/兼容补丁均保留。

本地仅能验证数学、映射、统计和部署保护。实际USD实例结构、碰撞过滤绑定、IK可达性、
新动力学下的平衡和击球效果，以用户容器输出为准；代理没有直接操作远程机器。
