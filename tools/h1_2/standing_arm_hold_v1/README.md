# 上肢目标保持对照：定位站立中的持续运动

已保存数据确认：原策略在名义条件下也有基座速度超限，双脚接触比例为1.0。
扰动后的高度/倾斜/漂移和原站立验收仍通过，严格安静性未通过。
采样中右肩pitch约2.6～3.3rad/s、腕部约2rad/s、躯干约1.6rad/s，
提示值得检查上肢控制活动；这些不是已确认的晃动原因，也不能由10Hz采样确定振动频率。

## 本轮只改变上肢目标

在Docker执行 `H1_2_arm_hold_v1_write_and_run_command.txt` 的全部内容。
它只新增 `tools/h1_2/standing_arm_hold_v1/`，跑2个新条件，各最多20秒：

| 条件 | 送入原站立step的动作改动 | 继续由原策略控制 |
|---|---|---|
| right_arm_default | 右肩/肘/腕7个残差动作设0，目标为原default_joint_pos | 双腿、躯干、左臂 |
| both_arms_default | 双臂14个残差动作设0，目标为原default_joint_pos | 双腿、躯干 |

实际关节仍受重力、原PD和力矩限值控制，可发生承重误差和运动；不是固定关节、
锁死刚体或固定基座。躯干保持策略控制。没有推力或速度扰动，无球，不训练。
原策略27维仍照常计算，归零只作用于送入环境的选定动作；模型/normalizer不更新。
每步校验选定关节实际下发目标确为默认值，非选定动作原样交给既有站立step。

动作历史和实际状态会随干预改变，策略后续反应也会改变。本轮能检验“限制上肢活动
是否改善安静性”，不能单凭改善就认定某个关节是唯一物理原因。
这个诊断会限制击球自由度，**不能直接作为最终乒乓球控制器**。

## 记录与比较

继续使用上一轮安静性阈值：参考高度±.05m、倾斜≤.08rad、漂移≤.08m，
线速度≤.10m/s、角速度≤.30rad/s、双脚Fz均>5N，不放宽任何阈值。
报告原站立验收、4.5～5.0秒/17～20秒稳定帧比例、各超限项、最大线/角速度，
以及关节速度RMS、目标角度逐控制步变化RMS/峰值。
quiet_candidate_pass要求完整20秒及原站立/估算负载验收通过，两窗口稳定比例均≥95%。

原策略基线读取已经保存的recovery_report.json，不重复运行名义站立或扰动测试。
此前保存的原策略窗口为参考，当前2条件与原8环境不是随机化同步配对试验。
若差异很小，需要保守解释，不能用环境数差异或数值差异证明因果。

新试验保存全部首次回合的控制帧（当前约50Hz）：原策略动作、归零后输入动作、
实际/目标角、关节速度、根节点状态、脚力、PD+FF估算负载。
统计在自动复位前完成，首次失败后不累计新回合，不忽略刚开始的瞬态。
50Hz控制帧仍不是200Hz物理子步记录；不直接声称得到了所有高频物理振动。

输出位于本次站立运行下唯一 `arm_hold_v1_<UTC>/arm_hold_report.json` 与完整轨迹。
贴回 `[ARM-HOLD] RESULT`、`TAIL_MISSES`、`TAIL_JOINT_SPEED_RMS` 或报错即可。
若要在Isaac Sim原生窗口观察，写入脚本后执行 `H1_2_arm_hold_v1_gui_command.txt`，
默认查看both_arms_default单环境，近实时，最多20秒，可修改condition选另一条件。

## 下一步的判别

- 如果限制上肢后安静性明显改善，优先设计上肢准备姿态/速度/目标变化的控制或奖励改动，
  保留model499为对照。新训练或正式控制器修改另行决定，不在本脚本自动启动。

  不能据此直接判定力矩不足或机械不合格。
