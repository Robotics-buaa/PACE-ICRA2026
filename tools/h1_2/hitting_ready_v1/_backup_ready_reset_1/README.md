# H1-2 独立准备位击球任务 — ready_reset_1

这是本地编写的待容器验收实现。没有连接或操作远程机器，没有进行 PyTorch/PhysX 运行，没有启动训练。准备位旧 GUI 预览仍未收到视觉确认；本包的 GUI 短验收会展示**直接从准备位开始**的新重置行为。

## 五项实施对应

1. `ReadyPlant.reset()` 在原 reset 完成后写入准备位、零速度、相同 PD 位置目标、零速度/前馈力矩目标。物理初始化只发生在 episode reset。自由根节点、重力、原 PD 和原资产保留。右臂零残差、27 路实际目标对应的旧参考残差、站立和新策略各自的历史均一致初始化；稀疏 reset 只清相应行。
2. 新策略七个动作严格按关节名称映射；目标为 `ready_q + clip(action, -1, 1) * range`。原 `default_joint_pos` 和中立拍心参考均不修改。冻结站立模型使用原 99×5 actor 观测、原动作参考、加载的原归一化器；动作历史填写相对于旧默认值的实际目标残差。新策略为 91×5=455 维 actor/critic 输入，不加载原 TT 模型或预测器。
3. 站立模型输出 27 路，取腿/躯干/左臂 20 路；新模型学习右臂 7 路。双臂目标均受几何保护。新策略直接看仿真球位置、速度及拍面法向，这不是部署到真实视觉系统的估计器。每回合一球，最多 4 秒，球落地或首次回球落台结束；验收使用 20 秒并忽略球落地终止。保留原训练发球范围，不冒称新的易球课程已验证。追球/全身解冻尚未实施，不自动进入下一阶段。
4. 复用原场景 session layer 中的 22 对自身碰撞和腕部补形状，启动时核对每个克隆的碰撞过滤、补形状质量及惯量。所有运行时几何使用批量 Tensor FK/SAT，不逐环境调用 NumPy。实际姿态每个物理子步检查；候选路径批处理采样；加入 0.08 秒速度前瞻、内部余量和边界接近惩罚。硬门槛仍为分离轴 1cm / 整拍前方 3cm / 右腕 2cm，身体法向接触 >0.1N 终止。无安全候选时发送实际姿态保持目标并记录失败，在该控制步结束后重置。它不是连续时间避碰保证。
5. `accept` 执行新的准备位 reset 短验收，无优化器更新；`train` 要求同版本通过报告和明确迭代预算；`evaluate` 只加载本任务的新七动作 checkpoint。所有输出写到独立日志目录。

## 动作与初始速度课程

七关节顺序：肩 pitch、roll、yaw、肘、腕 roll、pitch、yaw。

动作范围（rad）：`.45, .35, .45, .45, .60, .50, .50`。

双臂目标速度暂沿用肩/肘 `.6rad/s`、腕 `.9rad/s`；内部候选余量分别为 `.015/.05/.035m`。这些是初期保守参数，**尚未证明足以训练最终快速挥拍**。若训练触球稀少或大量受限，应根据已有新任务轨迹分析可达空间、速度、跟踪与负载，再修订独立版本；不能缩小硬门槛、关闭碰撞或盲目加 PD。

## 奖励与证据

- 接近球的连续小奖励只辅助探索，不计作命中。
- 真实球拍接触来自每个物理子步的球→球拍过滤法向力，阈值 `.01N`。
- 合法触球要求此前有本方台面反弹的真实接触证据，且来球 X 速度为负；无此前反弹的触球被罚，不获有效触球奖励。持续接触只奖励一次，分离后的重复触拍使该球失效。
- 出球方向使用触球后的实际速度；落点奖励要求触球后首次台面接触在对方区域，且出球向对方。台面反弹还要求向下到达和主要为垂直的接触力，网/边缘力不会独立计作落台。
- 平衡、动作变化、估算执行器负载和提前余量共同约束。负载是 PD 估算，不是实测电机力矩。
- 先结算奖励并记录终止前状态，随后 reset；边界/接触失败优先于无触球统计。训练完成仅表示优化器运行完成，不能代替真实有效回球评估。

1. 在已有 Docker 终端粘贴交付的 `H1_2_ready_task_install_command.txt` 全部内容。只写入 `/workspace/projects/PACE-ICRA2026/tools/h1_2/hitting_ready_v1/`。同版可重复安装；若发现该目录中未知编辑，拒绝覆盖。现有任务、资产、兼容补丁、模型和保护清单不变。
2. 运行 `H1_2_ready_task_accept_gui_command.txt`。8 环境新任务验收、直接准备位起步、20 秒零右臂动作、站立反馈控制其他通道。保留现有 DISPLAY，缺失时使用 `:1`。末尾打印 `[READY-ACCEPT] REPORT:`。
3. 贴回报告/失败日志和姿态视觉反馈。报告的 `passed=true` 只覆盖新初始化与站立短验收，GUI 外观仍由用户判断。无需再跑旧默认站立或旧混合击球回合。
4. 通过后用新的训练入口，指定预算。入口不设置默认训练次数。命令模板在外层实施说明里；不会自动启动长训。

## 短验收内容

- 所有环境初始 q=准备位、qdot=0、PD 目标=准备位；原模型参考不变；零动作目标正确。
- 每环境 20 秒：无保护终止、无身体接触超限、保留原硬门槛；高度不低于参考−.08m，倾角≤.15rad，漂移≤.10m，双脚支撑比例≥.9，估算负载比≤1.2，右臂最大跟踪误差≤.08rad。这些是初期工程判据，不是鲁棒性或击球验收。
- 污染偶数环境的关节状态、动作和历史后做稀疏 reset；确认这些行恢复一致，其他环境 q、目标、球、动作和历史保持。
- 构造新 runner，验证输出为 7 维且没有优化器更新；逐项核对冻结站立参数/归一化状态、默认参考及 PD 不变。
