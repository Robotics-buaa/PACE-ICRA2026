# H1-2 独立站立阶段1：可手动启动的短训与评估

此包只新增 `tools/h1_2/standing_v1_stage1/`，沿用已经通过接口检查的
`standing_v1` 任务，不修改它的源码、奖励、PD、资产或原任务注册。
不安装依赖，不加载旧乒乓球模型，不续训原模型，也不启用来球预测器。

## 执行顺序

1. 在现有 Docker 终端执行 `H1_2_stand_v1_stage1_prepare_command.txt` 的全部内容。
   它检查原保护清单、已经部署的站立文件和已通过的接口报告，只写入这个新增脚本目录。
   最后只显示新训练入口的 `--help`，不启动仿真或训练。
2. 核对下面的固定参数后，由用户手动执行 `H1_2_stand_v1_stage1_train_command.txt`。
   **第二条命令会真正开始这轮短训**。Codex没有直接执行远程训练。
3. 等待训练结束后的自动评估。贴回 `[STAND-TRAIN]`、`[STAND-EVAL]` 摘要或完整报错。
   无需重新运行已通过的接口、零动作或刚度扫描。

## 固定训练范围

| 参数 | 取值 |
|---|---|
| task | h1_2_stand_v1 |
| runner | 当前项目基础 OnPolicyRunner / PPO |
| 环境数 / 迭代数 | 512 / 500 |
| 每次迭代的每环境控制步 | 24 |
| 总控制转移数 | 6,144,000 |
| seed | 42 |
| 保存间隔 | 每100次迭代；最终model_499.pt |
| episode最长 | 20秒 |
| 初始化episode计数随机化 | 关闭，避免把随机计数当成存活时间 |
| 旧模型加载 / resume / predictor | 均关闭 |
| PPO其他超参数、网络与初始探索噪声 | 沿用当前H1 agent配置，保存到params/agent.yaml |
| 日志 | 本地TensorBoard，不连接外部服务 |

新的日志目录为 `logs/h1_2_standing_v1/<UTC唯一时间>_stand_v1_512x500_seed42/`。
训练不接收额外环境数/迭代数覆盖，避免误开完整训练。若需不同预算，先审查修改入口。
这是初次实验预算，不保证500次迭代已收敛。不自动延长，不自动恢复训练，不覆盖旧运行。
保存0/100/200/300/400和最终499迭代的checkpoint；原runner的迭代编号从0开始。

训练入口直接使用本次读取确认的当前项目 API，显式注册新任务后创建基础runner。
runner会pop配置中的class_name，所以在构造前保存完整配置副本；评估使用同一副本，
不混用旧乒乓球的配置或模型。模型确有更新、优化器step>0且参数有限后，才标记训练完成。
训练异常立即退出并保存报告，不自动加训练量或修改参数。

## 自动评估的含义

训练成功后先关闭仿真应用，再用新进程加载本次精确的 `model_499.pt`，
对8个环境的第一个回合执行最多20秒确定性策略推理。新进程通过exec替换训练进程，
释放训练GPU上下文。评估不更新权重，检查加载模型与checkpoint张量一致、推理前后
模型及normalizer状态不变、checkpoint和原文件hash不变。

测量位于check_reset内、自动复位之前；环境首次结束后的帧不再计入该环境统计。
同一环境连续失败几次不会被累计为“20秒站立”。不随机化episode计数，使用实际步数
和时长共同判断20秒。即使失败与超时同一帧发生，也不能只看timeout就算存活通过。

每控制步统计基座高度、倾斜、XY漂移、速度、双脚Fz、各关节目标误差和
同状态PD+FF估算负载。摘要使用全部帧；采样轨迹保留首帧、每10步和终止帧。

初始工程验收条件（不是厂家标准，也不是已验证的训练结果）：

- 连续20秒，无站立任务失败。
- 全程高度在几何参考0.999044m的±0.08m内；倾斜≤0.15rad；XY偏移≤0.10m。
- 双脚Fz均>5N的帧比例≥90%。脚link净力仍不是足底COP测量。
- 单独列出估算负载风险：任一关节估算负载≥95%限值的帧比例>5%，
  或估算峰值超过限值1.2倍，标记待分析。它不是实际驱动力矩或已证明的电机饱和。

摘要分别给出 `completed20s / kinematic / candidate` 的通过环境数。
candidate要求站立指标通过且未触发上述估算负载标记；应结合逐关节误差解释。
八个环境来自相同名义准备姿态，只有环境平移及数值差异，**不是8种独立扰动试验**。
本阶段没有推力或随机化，所以不能证明扰动恢复、拍面方向或有效击球。
原runner中通用的serve统计不作为这个无球任务的验收指标。

若通过，再设计小扰动及挥臂过渡；若未通过，先看时长、高度/倾斜走势及膝踝误差，
决定下一项局部改动。不自动进入追球或完整乒乓球训练。

## 输出和保留边界

新运行目录保留stage1_training_report.json、params、runner_config.pt、TensorBoard、
checkpoint，以及唯一evaluation_<UTC>/中的evaluation_report.json和采样轨迹。
失败也会保存能够生成的报告。原任务、保护清单、模型和兼容补丁均只读校验。

准备包只做过本地语法、打包、保护写入及统计逻辑测试；尚未在远程运行训练或评估。
