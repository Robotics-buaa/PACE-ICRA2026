## 四项实际修改

1. 身体目标固定在环境坐标 `(-1.8,0,z_ref)`，速度目标0；actor和critic使用同一个目标。
   球停放在远处高空，两种网络的球感知字段清零；球预测字段使用准备姿态下的固定拍心目标。
   因此不会让过期的来球预测继续牵引身体。双臂保持默认准备姿态的奖励，保留27动作自由度。
2. 替换本实验的奖励集合，移除击球/追球奖励；明确高度、直立、静止、位置和双脚支撑目标。
   `z_ref`使用原有几何校准约0.999m，尚不是经过承重验证的新高度参数。高度奖励宽度0.05m。
   其余正向站立奖励在高度低于`z_ref-0.12m`时关闭，到`z_ref-0.04m`恢复全权重，
   避免约0.80m深蹲仍拿满直立/静止奖励。基座始终自由、重力开启。
3. 所有动作经原全局裁剪/缩放后，再投影到运行时硬关节限位；训练和评估共用同一step实现。
   对越界请求、动作变化、软限位裕量、脚link运动和高PD估算负载施加惩罚。
   这只是新任务的动作约束设计，之前给旧策略加投影没有形成一致改善，不能当作现成修复。
4. 新站立episode最长20秒，不按发球次数结束；高度下降超过0.18m、倾斜超过0.45rad、
   身体XY偏移超过0.5m判为站立任务失败。保留明确失败终止，不用提前超时掩盖发散。

原正式PD与力矩/速度上限不改：髋/膝/躯干200/5，踝60/3，其余组保持现有资产配置。
阶段1仅关闭本实验的观测噪声、延迟、推力、附加质量及材质随机化，使用确定的默认重置。
这些只是初始实验条件，不能代替之后的扰动/随机化验证。
