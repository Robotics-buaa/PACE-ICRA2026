# 固定站立模型：第一轮小扰动恢复测试

本轮只加载已通过名义站立8/8验收的 `model_499.pt`，不训练、不修改任务/奖励/PD/模型，
不恢复来球、挥拍或追球。原名义站立评估直接读取其已保存报告，不重复执行。

## 当前具体操作

在现有Docker终端执行 `H1_2_standing_recovery_v1_write_and_run_command.txt` 的全部内容。
它检查已部署的stage1包和原保护文件，只新增 `tools/h1_2/standing_recovery_v1/`，
然后用既有Isaac Python运行下述8工况无界面测试。无需安装、重建环境或重新训练。
完成后贴回 `[RECOVERY] RESULT` / `[RECOVERY] SUMMARY` 及报告路径或报错。

## 工况与扰动含义

| 工况名后缀 | 第5秒的根节点质心水平速度增量 |
|---|---|
| x_pos_005 / x_neg_005 | 世界X方向 +0.05 / -0.05 m/s |
| y_pos_005 / y_neg_005 | 世界Y方向 +0.05 / -0.05 m/s |
| x_pos_010 / x_neg_010 | 世界X方向 +0.10 / -0.10 m/s |
| y_pos_010 / y_neg_010 | 世界Y方向 +0.10 / -0.10 m/s |

8个环境各对应1个工况，均从原准备姿态开始、同一seed42、最长20秒。
每个工况前5秒由原策略站立，第5秒叠加一次速度增量，之后仍由同一策略控制。
保留原有垂直和角速度，不写位置、不重置姿态，不使用额外纠偏控制器。
低强度和较高强度是并行独立工况，不会在同一个回合叠加两次。

该设计采用IsaacLab2.1提供的根节点质心速度写入接口，并立即读回PhysX速度核对增量。
这是模拟小冲击的**速度扰动**，不是持续施力，也不能换称某个牛顿数或实机抗推等级。
参考官方源码：[根节点速度写入](https://raw.githubusercontent.com/isaac-sim/IsaacLab/v2.1.0/source/isaaclab/isaaclab/assets/articulation/articulation.py)、
[push_by_setting_velocity](https://raw.githubusercontent.com/isaac-sim/IsaacLab/v2.1.0/source/isaaclab/isaaclab/envs/mdp/events.py)。

## 初始恢复判据

以下是本实验工程起点，不是厂家标准或已验证结果：

- 稳定带：高度在参考值±0.05m，倾斜≤0.08rad，XY偏移≤0.08m，
  基座线速度≤0.10m/s、角速度≤0.30rad/s，双脚Fz均>5N。
- 扰动前0.5秒的稳定帧比例≥95%；若不满足，标记pre_push_not_settled，
  不把原本未稳定的状态当作一个有效恢复起点。
- 扰动后3秒内，完成连续1秒全部落在稳定带内的窗口。
  输出recovery_s表示这个连续窗口**完成**时距扰动的时间，最短约1秒。
- 最后3秒稳定帧比例≥95%，且整个首次回合通过原20秒站立/估算负载判据。

所有统计在自动复位前记录；每个环境第一次结束后不再累计。
如果5秒前失败，不在复位后的第二回合补施扰动，会明确标记push_not_reached。
失败和超时同帧发生也不算成功。估算负载保持PD+FF含义，不是实际驱动力矩。
报告保留逐关节误差/估算负载；轨迹同时保留实际/目标角度、关节速度、根节点位置/速度和
双脚世界坐标受力，方便直接分析已保存数据。每5控制步采样一帧，摘要统计使用全部帧。

## 在Isaac Sim原生窗口看某一个工况

完成新增脚本写入后，可执行 `H1_2_standing_recovery_v1_gui_command.txt`。
它默认显示较小的世界+X速度扰动x_pos_005，一个环境、相机对准机器人、近实时播放。
终端会在扰动时打印PUSH，约20秒仿真结束；关闭窗口会记录测试中断，不记为通过。
可把 `--case x_pos_005` 改为表中其他工况名，不需要改代码或权重。
GUI沿用当前DISPLAY，空缺时默认`:1`；不配置新的显示环境。
